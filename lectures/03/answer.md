# 第3回 解答

## 演習

### 1. 第1回（素のLLM）とAIエージェントの回答の違い

第1回では、LLMが入力された質問に対して、主に自身の学習済み知識を利用して回答を生成していた。

一方、第3回のAIエージェントでは、LLMが質問内容に応じて外部ツールを選択・実行し、その結果を利用して回答を生成する仕組みを学んだ。

今回の演習では、「第2回の内容から確認問題を1問出して」という質問に対し、LLMが `make_quiz` ツールを呼び出し、用語集から取得した情報をもとに確認問題を出題した。

### 2. --traceで確認したツール呼び出し

以下のコマンドを実行した。

```bash
uv run python -m app.agent --trace "第2回の内容から確認問題を1問出して"
```

実行結果では、以下のツール呼び出しを確認した。

```text
[tool call] make_quiz({'lecture': 2})
```

ツールは第2回の用語から「Hugging Face Hub」を選択し、問題文と定義をJSON形式で返した。

LLMはその結果を利用して、「Hugging Face Hubとは何でしょう？」という確認問題を出題した。

### 3. LLMの呼び出し回数

`--trace` の実行結果は以下のとおりだった。

```text
requests=2
tool_calls=1
input_tokens=872
output_tokens=80
```

LLMの呼び出し回数は **2回**、ツールの呼び出し回数は **1回** だった。

これは、最初のLLM呼び出しで `make_quiz` の実行を判断し、ツールから結果を受け取った後、2回目のLLM呼び出しで最終回答を生成したためと考えられる。

### 4. 追加したツールとdocstring

今回、`app/tools.py` に `make_quiz(lecture: int) -> str` を追加し、`app/agent.py` に登録した。

ツールのdocstringには、以下の内容を記載した。

> 指定した回の用語から1つを選び、確認問題と答えを返す。
>
> 「第2回の確認問題を出して」のように、復習用の問題を求められたときに使う。

これにより、LLMがツールの用途と使用場面を判断できるようにした。

また、`--list-tools` で `make_quiz` を含む3つのツールが登録されていることを確認した。

最後に `uv run pytest -q` を実行し、**12件すべてのテストが成功**した。

### 5. 演習を通じて学んだこと

今回の演習を通じて、AIエージェントではLLMがすべての処理を行うのではなく、必要に応じてPythonで実装されたツールを呼び出し、その結果をもとに回答を生成することを理解した。

また、`INSTRUCTIONS` はエージェント全体の行動方針を、`docstring` は個別ツールの用途や使用場面を伝える役割を持つことを学んだ。

特に、`--trace` を利用することで、ツールの呼び出し内容やLLMの実行回数を確認でき、エージェントの内部動作を具体的に把握できた。

## 宿題
- 取り組んだレベル：基礎

- やったこと：
  AIエージェントの`INSTRUCTIONS`とツールの`docstring`を変更し、LLMの回答やツール呼び出しへの影響を比較した。
  ① `INSTRUCTIONS`から「必ずsearch_glossaryで用語集を確認する」という指示を削除し、「LoRAとは何ですか？」という質問で変更前後の動作を比較した。
  ② `search_glossary`の`docstring`を「用語を1つだけ入れる」から「まとめて入れる」に変更し、「LoRAとQLoRAの違いを教えて」という質問で動作を比較した。

- 結果：
  ① `INSTRUCTIONS`の変更前後で、どちらも`search_glossary`が1回呼び出され、LLMの呼び出し回数は2回だった。回答内容にも大きな違いは見られなかった。

  ② `docstring`を「まとめて入れる」に変更すると、`search_glossary({'query': 'LoRA QLoRA'})`が1回呼び出された。一方、「1つだけ入れる」に戻すと、LoRAとQLoRAが別々に検索され、ツール呼び出し回数は2回となった。LLMの呼び出し回数はいずれも2回だった。

- 気づき・疑問：
  `INSTRUCTIONS`の指示を削除してもツールが呼び出されたことから、LLMのツール選択には`docstring`も影響している可能性があると分かった。

  また、`docstring`の記述を変えるだけでツールの引数や呼び出し回数が変化したことから、AIエージェントではツールの実装だけでなく、説明文の設計も重要だと感じた。
